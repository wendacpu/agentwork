# 百条样本标注规范

## 你要产出什么

每条视频一个对象，字段固定为：

```json
{"videoID":"BVxxxx","description":"...","caption":"...","一级":"...","二级":"...","形态":"..."}
```

- **description**：只写画面里能看见的事。谁在做什么、场景、动作顺序、出现的物体与文字。不写推断、不写评价、不写看不到的部分（味道、气味、动机、效果）。
- **caption**：作者意图推断——这条片子想达成什么（教做法/播报事件/展示成果/引流到店/带货/科普/记录生活）。用"作者/该账号……"的表述，明确是推断。**不要写作者本人的保证或疗效**，遇到健康、投资、医疗类主张，加一句"该说法未获独立验证"。
- **一级/二级**：按下方枚举，选内容实际属于的领域，不是搜索关键词所属品类。允许与采集品类不同。
- **形态**：按下方枚举单选。

## 内容领域枚举

一级 6 个，二级如下（二级不在列表内时，选最接近的，不要自造新二级）：

| 一级 | 二级 |
|---|---|
| 资讯 | 时事社会 / 财经商业 / 科技数码 / 体育赛事 / 文娱热点 |
| 美食 | 探店 / 烹饪教程 / 街头小吃 / 烘焙 / 饮食文化 |
| 时尚美妆 | 美妆教程 / 护肤 / 穿搭 / 发型 / 好物分享 |
| 健康运动 | 健身训练 / 拉伸康复 / 养生 / 运动技能 / 体态矫正 |
| 知识科普 | 自然科学 / 历史人文 / 心理认知 / 生活常识 / 医学健康 |
| 生活记录 | 日常vlog / 旅行见闻 / 城市观察 / 居家整理 / 手工制作 / 宠物 |

## 内容形态枚举（单选）

教程演示 / 讲解分享 / 测评试用 / 开箱展示 / 探店体验 / 成果展示 / 现场记录 / 表演展示 / 剧情短片 / 访谈对谈 / 资讯播报 / 观点评论 / 直播切片 / 混剪合集

区分要点：
- **资讯播报**：以报道外部事件为主，信息优先，常见字幕条、时间地点标注。
- **现场记录**：以第一视角/在场记录为主，不强调播报腔。
- **讲解分享**：对着镜头讲观点、讲知识。
- **教程演示**：给出可复现的步骤。
- **观点评论**：以立场和论证为主，事件是引子。

## 证据要求

1. 先读 `metadata.json`（标题、作者、采集品类）与 `asr_raw.json`、`ocr_raw.json`。
2. 必须用 read_image 看图，至少首、中、末三帧；内容复杂时补 1-2 帧。**只看标题或字幕下结论是不合格的**。
3. ASR/OCR 是未纠错的机器识别，错字很多；只用来辅助判断在讲什么，不要把识别原文抄进 description。
4. 画面与标题矛盾时，以画面为准，并在 description 里写出实际看到的内容。
