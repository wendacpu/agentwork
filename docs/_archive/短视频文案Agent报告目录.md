# 短视频推荐文案质量优化 Agent

## 一、项目背景

1. 目标用户与使用场景
2. 原有文案生产与审核流程
3. 生成、审核和规则维护中的主要问题

## 二、项目目标

1. 文案质量：每批视频中产出可用标题的比例
2. 审核效率：审核人员筛选和判断标题的时间
3. 风险与成本：事实错误、错误放行和单条可用标题的成本
4. 对审核人员、内容运营人员和组织的价值

## 三、产品方案

1. 整体运行机制
2. 内容理解：识别视频主旨、看点和可写边界
3. 文案生成：生成候选标题并按问题定向重写
4. 质量评审：检查事实、内容匹配、表达和业务规则
5. 人机分工：工具做固定校验，模型负责语义判断，人工确认最终采用

## 四、测试与验证

1. 验收标准：什么样的标题可以使用
2. 测试用例：内容理解、生成、评审与异常处理
3. 模型选型：比较质量、成本与耗时
4. 效果验证：简单链路对照、影子运行与后续线上测试

## 五、Bad Case 回收与优化

1. 问题定义：哪些标题和运行结果属于 Bad Case
2. 问题发现：人工反馈、运行日志、规则拦截和抽样检查
3. 分类与分级：按出错环节、问题类型和影响程度归类
4. 问题记录：保存原视频、原始标题、人工意见、系统输出和版本信息
5. 定位与修复：区分材料、理解、看点、表达、评审与程序问题
6. 验证与回流：复测原案例和反例，经确认后进入案例库或回归测试集
7. 持续监控：统计各类问题数量、重复出现情况和修复进度
8. 典型案例：一个真实问题从发现、定位到修复验证的过程

## 六、项目结果与后续计划

1. 已完成的验证与阶段结果
2. 尚待验证的质量、效率和成本指标
3. 后续试用与线上效果验证
