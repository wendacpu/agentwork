## 三、代码层确定性缺口（本轮静态核实）

1. 主旨字段被丢弃：模型按 HIGHLIGHT_PROMPT 必须输出 main_thesis，但 _normalize_highlights 只读 highlights，从未读取 main_thesis；该字段既不落库也不进生成。本批 18/18 条 state 里 main_thesis 为空。证据：agent_system/pipeline.py 第 788-820 行。
2. 主看点 relation 未强制：relation 被写入 Highlight，但没有校验“主看点必须为 core”。R13 的主看点是 support 单元，仍然进了 handoff。
3. 结构候选可顶掉主旨单元：_structural_candidates 生成 turn-* / axis-* 并由 fallback 注入；R10 的主看点因此变成单条反差 turn-3，而不是 su-01 整段“装死→藏枪→刺杀”的主线。（2026-11 更新：缺少独立关系证据契约，程序已停止合成 turn/axis 候选，也不再用 fallback 注入；原始 events/turns 仅作为待评审线索。见 README「运行结果边界」。）
4. N03 主旨框架偏差：演示/教程类视频里，thesis 被写成“作者以超详细手法教…”这类元描述，而不是“怎么做、做成什么效果”，于是标题自然写成“超详细教程”（R18）。
