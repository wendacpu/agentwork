# 领域规则 V

领域匹配表示内容领域相关，不会把所有偏好变成硬性必填。

### V01 生活／宠物

【看点】优先提炼动物的具体动作、与环境或人物的互动、行为前后变化。物种、品种、年龄、关系只有证据明确时使用。
【写法】围绕“动物＋具体动作/互动”组织标题；发生有趣变化时呈现真实变化。可使用读者能识别的轻度拟人，如几只猫围坐被称作“开会”。
【边界】不从表情或单次动作推断生病、报恩、嫉妒、救主、知道主人失业等动机或诊断；不能把训练剪辑写成天生能力，把偶发行为写成普遍习性。
【审查重点】动物与人的关系是否有依据；行为是否被改写成人类动机；“救了、保护、治好了”等结果是否充分支持；拟人是否会形成真实事实误解。
【自拟例】材料：猫把地上的玩具逐个叼进纸箱。可写“玩具散了一地，小猫挨个叼回箱子”。不可凭空写“心疼主人太累，小猫主动包揽家务”。

### V02 时尚美妆／彩妆

【看点】提炼具体部位、妆面风格、上妆动作、配色和材料中清楚呈现的变化；教程突出关键方法，展示突出可见妆效。
【写法】选“部位＋操作/效果”或“场景＋妆容特点”。颜色、产品名称、色号、妆容风格需有依据，不凭模糊画面硬认。
【边界】不将灯光、滤镜、角度变化直接归因于产品；不把单人体验写成所有肤质适用；无依据不写持妆时长、防水效果、成分功效和治疗效果。正常化妆不自动构成前后效果证明。
【审查重点】视频是否实际展示步骤；“教程”是否过度承诺；视觉变化是否被升级为长期效果；是否杜撰产品或脸型肤质信息。
【自拟例】材料：作者完整演示用棕色眼线胶笔画细眼线。可写“棕色细眼线，这样一笔笔画出来”。不可写“一笔放大双眼，所有眼型都适合”。

### V03 时尚美妆／美甲

【看点】提炼指甲的配色、图案、质感、甲型和实际演示的制作步骤；仅有成品时突出成品特点。
【写法】用“配色/图案＋美甲特点”，或在有步骤时使用“具体工艺＋呈现效果”。术语须有明确材料支持；无法辨认工艺时改用可见外观描述。
【边界】成品展示不能包装成完整教程；不添加价格、持久天数、无伤害保证、人人适合等承诺；不要把画面中的反光误认成特定材料。
【审查重点】是否误认甲型或工艺；是否承诺视频未讲的方法；是否把个体效果扩大为普遍效果。
【自拟例】材料：展示蓝色底色与银色星点的成品美甲，无操作过程。可写“蓝色甲面上，点着细细的银色星光”。不可写“零基础三分钟学会这款星空美甲”。

### V04 社会生活／城市见闻

【看点】提炼具体城市场景、可见行为、设施或公开活动中的变化；涉及公共事件时先确认时间、主体、地点、来源和已知进展。
【写法】选择足以消歧的事件锚点，不要求人地事物数字全部出现。普通街景可用“地点/场景＋具体见闻”；历史记录、演绎或个人说法会引发误读时加相应限定。
【边界】不能从人群聚集、车辆停靠等画面推断事故原因、行政措施、案件性质或最终处置；不把个人经历扩展为全城普遍情况；不把旧事件包装成近期新闻。
【审查重点】是否混淆地点与发布者所在地；是否把推测写成事实；是否擅加伤亡/责任/身份信息；标题是否泄露不必要的身份信息；事件是否仍有效。
【自拟例】材料：已确认是某城市 2023 年的夜市记录，展示糖画摊制作过程。可写“回看2023年的夜市，糖画在勺下成形”。不可写“今晚夜市爆满，全城人都来排队”。具体地名只有有依据且有助理解时加入。

### V05 美食／肉类料理

【看点】提炼明确的食材、烹饪动作、处理顺序、成品外观及材料支持的制作差异；教程与成品展示分开处理。
【写法】优先“菜品/食材＋关键动作”，或“制作过程中的具体变化”。作者对口感的体验需要归属；仅凭画面只能写可见状态。
【边界】不补写吃起来的口感、地域正宗性、烹饪成功率、卫生安全保证或营养治疗效果；无实测不写“只需几分钟”；不能把剪辑时长当烹饪时长。
【审查重点】食材与菜名是否识别正确；步骤与时间是否来自材料；画面特征是否被写成口感或安全结论；是否过度承诺新手必成。
【自拟例】材料：排骨先煎上色，再放入酱汁焖煮，完整展示过程。可写“排骨先煎上色，再裹上一层酱汁”。不可写“五分钟软烂脱骨，怎么做都不失败”。

### V06 美食／餐饮探店

【看点】提炼门店特色、菜品、现场制作、环境、实际点单和作者有归属的体验；价格只有条件明确时才可做主要看点。
【写法】围绕“明确场景/门店特色＋具体体验”组织；店名/地点无可靠依据时退回可确认的场景描述。报价必须保留单位、份量、人数、套餐或活动等影响理解的条件。
【边界】一次消费不代表长期水平；历史价格不代表现价；团购/限时/套餐价不等于日常单品价；不凭评价宣称全城第一、必吃或人人满意。商业合作背景已知且会影响理解时，依业务规则保留必要说明，不伪装独立客观测评。
【审查重点】价格和条件是否同步出现；是否编造排队、口碑、营业状态；个人口味是否写成客观定论；是否含未经允许的导流或促销。
【自拟例】材料：2024 年探店视频展示当时 39 元的双人套餐。可写“回看这次探店：39元双人套餐里有什么”。不可写“现在39元随便吃，全城最划算”。如果长度无法保留时间与条件，就换用菜品或制作看点。

### V07 美食／水果品鉴

【看点】提炼有依据的品种、果肉外观、切开过程、明确的品尝反馈，以及同条件下的实际比较。
【写法】视觉看点写可见颜色、大小、结构与动作；味觉看点保留“作者尝后认为”等归属；有仪器读数时可呈现这次样本的测量结果。
【边界】不把颜色直接当作甜度、成熟度或无农残证据；不将单个果实读数推广到整个品种；不把仪器数值改写为精确含糖量，除非材料明确且有相应依据；不增加产地、等级或健康功效。
【审查重点】品种产地是否被猜测；口感是否出自真实陈述；数值的单位、对象和测量条件是否明确；比较是否同条件且实际发生。
【自拟例】材料：切开一颗果肉为红色的梨，品种未知，无试吃。可写“这颗梨切开后，果肉竟是红色的”。不可写“最甜红心梨，吃一口抵十个苹果”。

### V08 健康运动／体态训练

【看点】优先描述具体动作、训练部位、器械与演示过程；动作名称不确定时用清楚的可观察动作描述。
【写法】用“明确动作/部位＋演示或练习”表达；教程确有步骤时可写学习方向。与适用人群、限制或健康效果有关的信息，必须按证据与已加载业务规则处理。
【边界】不能从站姿或外观给个人诊断；不能把短期姿态、镜头角度、灯光差异当作长期体态改变；不承诺几天矫正、治好疾病、必瘦或人人适用。作者的疗效自述本身不构成治疗有效性的证明，加“据说”也不能放行。
【审查重点】是否把动作演示包装成医疗诊断/治疗；是否虚构效果期限、减重数字或适用保证；是否遗漏会改变用户理解的必要条件；是否用羞辱身体或疾病恐惧吸引点击。
【自拟例】材料：作者演示靠墙抬臂动作，没有临床或效果评估资料。可写“靠墙抬臂，这个动作这样做”。不可写“每天三分钟，七天治好圆肩”。本规则只限定文案，不提供运动处方或医疗判断。

### V09 泛娱乐／兽装表演

【看点】提炼兽装角色的外观、表演动作、舞蹈与互动场景；角色名称、设定和表演者身份需要明确来源。
【写法】用“兽装角色/表演者＋具体动作或互动”。当普通用户可能把角色当成真实动物或虚构事件时，明确“兽装”“表演”等属性；角色身份不明时使用可确认的泛称。
【边界】不把兽装角色当作真实动物，不把设定当成表演者现实身份；不从装扮推断年龄、性别或私生活；不将普通表演性化、污名化，也不虚构与观众的情感关系。
【审查重点】是否交代表演性质；是否混淆角色和真人；是否错误识别角色或活动；是否因领域刻板印象误判违规。
【自拟例】材料：兽装表演者在舞台跟随音乐转圈，无角色名资料。可写“兽装角色跟着节拍，在舞台上转起圈”。不可写“真狐狸登台成精，现场观众都吓坏了”。

### V10 音乐／现场演出

【看点】提炼有依据的表演者、曲目、乐器、演奏/演唱动作、编排变化，以及画面或音频明确支持的现场互动。
【写法】用“表演者/乐器＋具体表演看点”；身份未知时以明确的场景与动作替代。曲名、原唱、翻唱、首演、即兴等标签必须有依据。
【边界】不把翻唱写成原创或原唱亲临；不凭混音和画面判定全开麦、假唱、声压或技术纪录；不把少数人的反应写成全场落泪；旧现场不能暗示正在直播。
【审查重点】人名曲名与演出归属是否正确；是否将歌词叙事当作歌手真实经历；是否用孤立歌词替代观看内容；是否夸大现场反应或演唱能力。
【自拟例】材料：街头歌手演唱时，前排几位观众跟唱；曲名不明。可写“街头歌手唱到副歌，前排观众跟着合唱”。不可写“万人现场泪崩，原唱听完都认输”。

## 一级领域规则（按数据集 six-domain taxonomy 补，2026-11）

> 下面 V11–V16 对齐 `data/source/content_taxonomy.md` 的六个一级领域：资讯 / 时尚美妆 / 美食 / 生活记录 / 健康运动 / 知识科普。V01–V10 是早期采集垂类（宠物/美甲/兽装/水果/音乐等），当前 100 条样本基本不触发，保留备查，后续再决定去留。

### V11 资讯（时事社会 / 体育赛事 / 财经商业 / 文娱热点 / 科技数码）

【看点】事件主体、时间、地点、来源、已知进展；体育写赛果、比分、关键动作或选手；财经写公司、市场、数据或政策；科技写产品、规格或发布动作；文娱写人物、作品或事件节点。
【写法】用「主体＋动作/结果」短句；数字带单位；有二手来源时保留归属（据 X / 报道称 / 网传）；旧事件要标时间或「回看」。
【边界】不把推论、原因、责任写成已证实；不写未经证实的伤亡、结果、目的；不把旧事件写成当前；不把个人说法写成官方；体育不写未发生的赛果；财经不写投资建议或收益承诺；科技不写未发布功能；文娱不把传闻写实。
【审查重点】主体 / 时间 / 数字 / 地点是否准确；来源是否保留；转述是否被写成事实；是否把某个局部的意义放大成全局结论。
【自拟例】材料：转播画面显示西班牙 1-0 领先，解说提到费兰补时破门。可写「费兰补时破门，西班牙 1-0」。不可写「西班牙夺冠，费兰封神」。

### V12 时尚美妆（穿搭 / 发型 / 美妆教程 / 好物分享 / 护肤）

【看点】具体单品、部位、妆容、发型、搭配组合、上妆或造型步骤、配色与材质、可见的前后变化；好物写使用场景与作者归属的体验；护肤写产品与步骤。
【写法】「单品＋搭配」或「部位＋操作/效果」；产品名、色号、发型名须有依据；步骤按视频实际展示写，不补未展示的环节。
【边界】不把灯光、滤镜、角度变化当成产品效果；不承诺持妆、防水、成分功效或治疗效果；单人体验不写成所有人适用；不编产品价格、成分、肤质适用范围。
【审查重点】步骤是否真实展示；产品、色号是否杜撰；是否过度承诺；前后对比是否被错误归因于产品。

### V13 美食（饮食文化 / 烹饪教程 / 街头小吃 / 烘焙）

【看点】食材、处理动作、顺序、火候、成品外观与制作差异；街头小吃写摊位、小吃与制作方式；饮食文化写地域、习俗与食物；烘焙写配方、步骤与成品。
【写法】「菜品/食材＋关键动作」，有步骤时按实际步骤写；口感、价格、份量须带归属或条件。
【边界】不补写未实测的口感、正宗性、成功率或卫生安全；不把剪辑时长当烹饪时长；不写「几分钟搞定 / 零失败」除非材料支持；街头小吃不编排队、口碑或营业状态。
【审查重点】食材 / 菜名是否对；步骤 / 时间是否来自材料；是否过度承诺；价格与份量条件是否保留。

### V14 生活记录（日常 vlog / 城市观察 / 手工制作 / 居家整理）

【看点】具体场景、可见动作、手工的材质、过程与成品、居家的整理前后变化、vlog 的日常片段与情绪节点。
【写法】「场景/物品＋具体动作」；手工写材质与关键步骤；居家写可见的前后差别，不写主观「变高级」。
【边界】不从画面推断人物情绪、动机、疾病或关系；不把个人经历扩展为普遍；手工不写未展示的工艺；居家不写「必学 / 一劳永逸」。
【审查重点】是否把猜测写成事实；是否夸大效果或因果；是否泄露过多个人信息。

### V15 健康运动（健身训练 / 运动技能）

【看点】具体动作、训练部位、器械、动作要领与演示过程；运动技能写关键动作、节奏与发力点。
【写法】「动作/部位＋演示或要领」；动作名不确定时用可见描述；涉及效果必须带限定或归属。
【边界】不诊断、不治疗、不承诺几周见效、必瘦或人人适用；作者疗效自述不构成证明；不写医疗或运动处方建议。
【审查重点】是否把演示包装成医疗或治疗；是否虚构期限与效果；是否遗漏会改变理解的限定。

### V16 知识科普（自然科学 / 历史人文 / 生活常识）

【看点】具体现象、知识点、原理、历史事件或人物、生活常识的适用条件与边界。
【写法】「现象/对象＋关键结论」；结论须有材料支持，作者观点须归属；历史细节以材料为准。
【边界】不把观点、假说写成定论；不把个别现象写成普遍规律；历史不写未经证实的细节；生活常识不写「一定 / 万能 / 包治」。
【审查重点】结论是否有依据；是否过度概括；是否把推测写成事实。
